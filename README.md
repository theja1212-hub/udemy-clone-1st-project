# Udemy Clone

A responsive clone of the Udemy learning platform built with HTML and CSS, replicating the core UI/UX elements of the popular online learning marketplace.

![Project Banner/Screenshot](link-to-screenshot.png)

## 🌟 Features

- Responsive navigation bar with search functionality
- Hero section with call-to-action buttons
- Course cards grid layout
- Category browsing section
- Footer with multiple link sections
- Mobile-friendly responsive design
- Clean and modern UI matching Udemy's design language

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox/Grid for layouts
- Media Queries for responsiveness

## 📋 Prerequisites

No special prerequisites needed! Just a web browser to view the website.

## ⚙️ Installation

1. Clone the repository
```bash
   https://github.com/theja1212-hub/udemy-clone-1st-project.git
```

2. Navigate to the project directory
```bash
   cd udemy-clone
```

3. Open `index.html` in your web browser
```bash
   open index.html
```
   Or simply double-click the `index.html` file
